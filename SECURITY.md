# Security and privacy

This repository contains no hosted service and does not collect telemetry.

- Review inputs before sharing them with an agent or external service.
- Do not commit credentials, private transcripts, student records, customer data, or exports.
- Use synthetic data when filing an issue or reproducing a bug.
- Report security problems privately through GitHub Security Advisories.

The maintainer will acknowledge a reproducible report and publish a fix or documented mitigation when appropriate.
